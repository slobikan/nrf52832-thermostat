# СОЗДАНИЕ АНДРОИД ТЕРМОСТАТ

## Контекст проекта
- Основной проект: климат-контроллер на ESP32 + nRF TX/RX.
- ESP32 отвечает за UI, MQTT, Home Assistant, меню, часы/RTC.
- nRF TX — передатчик с датчиком/энкодером.
- nRF RX — приёмник, который принимает радио от TX и общается с ESP32 по UART.

## Ключевые папки
- ESP32: `D:\TERMOSTAT\ESP32 Proekt`
- nRF: `D:\TERMOSTAT\thermostat2`
- TX TM1621B KiCad: `D:\TERMOSTAT\KiCad TX TM1621B`

## Что уже сделано
- Меню ESP32 сильно расширено: MODE, ZONES, SYSTEM, INSTALLER MENU, SERVICE MENU.
- Подключён Home Assistant через MQTT.
- Подключён DS1302 к ESP32.
- Сделаны KiCad-проекты и производственные файлы для TX-варианта с TM1621B.
- Работает синхронизация TX/RX.
- Температура и порог от TX доходят до ESP32 и видны в Home Assistant.

## Текущий важный статус на 2026-03-20
- Home Assistant видит изменение порога, если менять его энкодером на TX.
- Но изменение порога из Home Assistant в обратную сторону пока нестабильно/не работает как нужно.
- Последняя диагностика показала:
  - Home Assistant -> MQTT -> ESP32 работает.
  - ESP32 отправляет UART-команды в сторону RX.
  - RX продолжала отдавать старый TARGET в heartbeat.
- В ESP32 уже прошита новая версия на COM3.
- RX прошита свежей версией через OpenOCD.

## Важные пины ESP32
- TFT: 32, 33, 25, 26, 27, 14
- UART к RX: 16, 17
- Кнопки: 4, 13, 18, 23
- DS1302: 15, 2, 5
- Под W5500 зарезервированы: 19, 21, 22

## Важные пины RX nRF
- UART RX: P0.05
- UART TX: P0.06
- Выход: P0.24
- Status: P0.25
